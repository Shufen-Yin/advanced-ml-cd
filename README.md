# Advanced ML Continuous Deployment - Assignment 3

## Project Description
This repository contains a containerized sentiment analysis API built with FastAPI and an ONNX model. It features a fully automated CI/CD pipeline using GitHub Actions to ensure code quality and model robustness.

## Features
- **FastAPI Backend**: Efficiently handles sentiment analysis requests.
- **ONNX Model**: Uses a high-performance pre-trained model format.
- **Dockerized**: Multi-stage build for a minimal and secure container image.
- **CI/CD Pipeline**: Automated building and testing on every push to `main`.

## Prerequisites
- Python 3.10+
- Docker
- Git
